# Contributing

Thanks for helping make Beyond Average better. This repository holds the public docs, setup examples and issue tracker. The apps themselves are developed privately, so code changes to the suite don't come through here, but there's still plenty to do.

## Report a bug

[Open an issue](../../issues/new/choose) with:

- what you did, what you expected and what happened
- the app and version (Hub → Apps), or `ba --version` for the CLI
- for MCP problems: your AI client and its version
- the error text or a screenshot

Leave out anything private: paths with your user name, API keys, tokens, place files you don't want public.

## Suggest a feature

Open an issue and tell us the problem you're trying to solve in your Roblox game, not only the feature you have in mind. A short clip or a reference game helps.

## Fix the docs

Pull requests to the docs and examples are welcome:

1. Fork the repo and make your change on a branch.
2. Keep the style: short sentences, plain words, copy-paste examples that work as written.
3. Test any config or command you change on a real setup.
4. Open a pull request saying what you changed and why.

By contributing, you agree your changes are licensed under the [MIT License](LICENSE).

## Add an MCP client

Using Beyond Average with a client that isn't in [docs/mcp-setup.md](docs/mcp-setup.md)? Send a pull request with the client's config location, a working example and the client version you tested.

## Be kind

Be respectful and helpful to everyone here. We'll remove comments that aren't.
